# Изменения

## 0.1.0-alpha.15

Релиз: [Docs/RELEASE-0.1.0-alpha.15.md](Docs/RELEASE-0.1.0-alpha.15.md).

- Обновление из GitHub Releases: раздел в настройках, проверка по кнопке, загрузка, проверка SHA-256 и подписи, замена приложения и перезапуск.
- Статус движка отражает реальное состояние (модель, ключ, список языков).
- Раздел Chromium: «Установить» и «Удалить» расширение; переключатель только включает и выключает мост.
- Расширение и раздел настроек Safari.
- FAQ по получению ключей Google и Yandex.
- Исправлено переключение светлой и тёмной темы, «Системная» следует за macOS.
- Исправлена утечка `URLSession` в облачных движках; быстрее старт локальной модели (APFS-клон), выгрузка runtime в простое, Live пропускает OCR при неизменном кадре, реже просыпается native host, память переводов пишется в фоне, очищаются остатки `/tmp/koto-*` после краха.
- Chrome 0.1.4 без изменений.
