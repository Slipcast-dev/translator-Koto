# Security

The current alpha branch is the only supported branch; no preview SLA is promised. Relevant areas include text handling, Keychain, runtime/model integrity and native messaging.

Do not disclose secrets or private exploit details in a regular issue. Use the private Report a vulnerability form if available under Security. Otherwise, contact the owner through [Slipcast-dev's public contacts](https://github.com/Slipcast-dev), initially without exploitation details, and agree on a private channel. Russian and English reports are welcome.

A fix requires a minimal reproducer and verification without user data. Do not bypass Gatekeeper/TCC for testing.
