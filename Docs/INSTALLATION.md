# Установка Koto 0.1.0-alpha.16

Apple Silicon, macOS 26+. Проверки выпуска выполнены на macOS 27.2; macOS 26 не запускалась.

1. Скачайте DMG и SHA256SUMS.txt из [alpha 16](https://github.com/Slipcast-dev/translator-Koto/releases/tag/v0.1.0-alpha.16).
2. Сверьте `shasum -a 256 Koto-0.1.0-16-arm64-preview-ci.dmg` с SHA256SUMS.txt.
3. Откройте DMG и перенесите Koto.app в Applications.
4. При необходимости выдайте доступы для выделения/OCR через настройки Koto.

Preview имеет ad hoc подпись без Developer ID/notarization, macOS может отказать в запуске. Скрипты не отключают Gatekeeper и не изменяют доверие системы. Альтернатива — [сборка из исходников](BUILDING.md). После замены ad hoc сборки может потребоваться заново добавить текущий Koto.app в системные списки и перезапустить его. Пароль/Touch ID подтверждает владелец Mac.

Для Apple выберите языки и нажмите «Перевести». Если появится «Подготовить языки», выполните явную подготовку. Для необязательной Qwen используйте кнопку установки модели: [MODELS.md](MODELS.md).

## Chrome 0.1.4

В настройках Koto (раздел «Браузер Chromium») нажмите «Установить расширение для Chrome»: Koto зарегистрирует native host, положит файлы расширения в `~/Library/Application Support/dev.slipcast.koto/ChromeExtension`, откроет эту папку и `chrome://extensions`. Chrome требует подтверждения: включите режим разработчика, нажмите «Загрузить распакованное расширение» и выберите открывшуюся папку. ID: `bodbmpckhpjhkkhhadamlbkddaikilok`. Переключатель «Разрешить браузерный мост» лишь включает и выключает работу расширения и ничего не удаляет; «Удалить расширение» убирает регистрацию host и файлы (само расширение удаляется в Chrome). После обновления Koto нажмите «Установить расширение для Chrome» ещё раз и перезагрузите расширение. Вручную можно использовать BrowserExtension из DMG либо Koto-Chrome-0.1.4.zip. На вкладке HTTP(S) нажмите Koto и выберите действие; внутренние страницы Chrome исключены.

При ошибке Apple-ресурсов выберите ту же пару в Koto и нажмите «Перевести». Если предложена подготовка — выполните её, затем повторите действие в браузере.

## Safari

Расширение Safari встроено в Koto.app (`Contents/PlugIns/Koto Safari.appex`). Переместите Koto в «Программы», запустите его один раз и в разделе «Браузер Safari» нажмите «Включить в Safari» (откроются настройки расширений). Предварительная сборка не подписана Apple Developer ID, поэтому сначала включите в Safari меню «Разработка» → «Разрешить неподписанные расширения»; выбор сбрасывается при выходе из Safari. Расширение использует тот же мост и тот же переключатель, что и Chrome. **Не проверено в реальном Safari:** сборка, встраивание, подпись и клиент моста проверены автоматически, а включение расширения и перевод внутри Safari требуют ручной проверки на вашем Mac.

## Обновление

Раздел «Обновление» открывает настройки: версия, описание и кнопка «Проверить обновления». Проверка обращается к GitHub Releases только по нажатию. Если есть более новая версия, появляется окно с номером, описанием и размером. «Установить и перезапустить» скачивает DMG, сверяет SHA-256 с SHA256SUMS.txt выпуска, проверяет, что внутри именно Koto более новой версии с действительной подписью, подготавливает копию рядом с приложением и после выхода заменяет его и запускает заново. Для этого папка с Koto.app должна быть доступна для записи. Любой этап ограничен тайм-аутом, загрузку можно отменить.

## Удаление

Завершите Koto и удалите app. При необходимости удалите расширение Chrome и регистрацию `~/Library/Application Support/Google/Chrome/NativeMessagingHosts/dev.slipcast.koto.json`. Настройки/память/модель в `~/Library/Application Support/dev.slipcast.koto` и ключи Keychain — отдельные пользовательские данные; удаление приложения не должно молча уничтожать их.

## Язык интерфейса

Koto поддерживает русский и английский; резервный язык — английский. Язык приложения выбирается средствами macOS и применяется после перезапуска. Chrome использует свой язык независимо. Языковая пара перевода сохраняется. Числа следуют региону. Пояснения запрашиваются на языке Koto, варианты — на языке перевода, цитаты остаются в оригинале.
