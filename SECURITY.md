# Безопасность

Поддерживается только текущий выпуск; SLA не обещается. Важны обработка текста, Keychain, integrity runtime/модели и native messaging.

Не публикуйте секреты или приватные exploit-данные в обычном issue. GitHub Private Vulnerability Reporting включён: используйте [Report a vulnerability](https://github.com/Slipcast-dev/translator-Koto/security/advisories/new). Отчёт передаётся сопровождающему приватно. Email/PGP не заявлены; отдельные контакты не выдумываются.

Сообщения принимаются на русском и английском языках.

Исправление требует минимального воспроизводимого примера и проверки без пользовательских данных. Не обходите Gatekeeper/TCC ради тестов.

## Модель угроз

- **Граница — учётная запись пользователя.** Мост с браузером защищён сокетом и токеном (`bridge.token`, права 0600, только пока мост включён). Любой процесс того же пользователя может прочитать токен и обращаться к мосту, в том числе подставить `pageOrigin` и обойти список исключённых сайтов. От вредоносного кода под вашей учётной записью Koto не защищает; от других пользователей и процессов в песочнице — защищает.
- **Обновления.** Приложение ставит только выпуск, у которого `SHA256SUMS.txt` подписан ключом Ed25519 разработчика (публичный ключ вшит в приложение), а файлы взяты из релизов этого репозитория. Подпись приложения — ad hoc: Developer ID и notarization пока нет, поэтому Gatekeeper не подтверждает издателя, а приложение при обновлении не снимает карантин.
- **Память переводов** (необязательная) хранится открытым JSON с правами 0600; облачные ключи — в Keychain.
- Основное приложение работает без App Sandbox (ему нужны захват экрана, локальный runtime и мост); расширение Safari — в песочнице.
