Подпись не является Apple Developer ID. Приложение не нотарифицировано.
macOS может заблокировать запуск. Koto не отключает Gatekeeper и не меняет доверие системы.

Перенесите Koto.app в Applications. Инструкции: Docs/INSTALLATION.md.
English instructions: README.en.txt and Docs/INSTALLATION.en.md.

Интерфейс Koto и расширения поддерживает русский и английский.
Koto следует языку приложения в macOS; Chrome выбирает язык расширения отдельно.
После смены языка Koto перезапустите приложение. Языковая пара сохраняется.
Региональные числа не зависят от языка интерфейса.

Apple Translation работает на Mac с системными языковыми ресурсами.
Необязательная Qwen устанавливается кнопкой «Установить модель» в настройках.
Модель около 2,5 ГБ не включена в приложение и DMG; веса хранятся в Application Support.
Пояснения запрашиваются на языке Koto, варианты — на целевом языке.
Проверки структуры ответа не гарантируют смысловую точность Qwen.

Google/Yandex требуют вашего API-ключа в Keychain. Выбор облачного движка
отправляет текст провайдеру; для захвата, Chrome и Live нужны отдельные разрешения.
Автоматического перехода в облако нет. История браузерного текста не сохраняется.

Chrome: chrome://extensions → режим разработчика → загрузить распакованное
расширение из BrowserExtension. В настройках установленной Koto зарегистрируйте
native host и включите браузерный мост. Не регистрируйте host из смонтированного DMG.

Горячие клавиши: Control+Option+Command+T — выделение, +R — OCR, +L — Live.
Доступы macOS выдаёт владелец Mac. Оригиналы лицензий сохранены в пакете.
Границы проверок: Docs/LOCALIZATION.md. Пакет подготовлен локально и не опубликован.
