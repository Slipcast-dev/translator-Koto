# Изменения

## 1.0.0

Релиз: [Docs/RELEASE-1.0.0.md](Docs/RELEASE-1.0.0.md).

- Первый стабильный выпуск: без пометок alpha, тег `v1.0.0`, файлы `Koto-1.0.0-20-arm64.dmg`. Подпись по-прежнему ad hoc, без Developer ID и notarization.
- Перевод выделенного текста работает и там, где приложение не отдаёт выделение через Универсальный доступ: Koto коротко копирует выделенное (⌘C) и возвращает прежнее содержимое буфера. Парольные поля не читаются.
- Область экрана: окно перевода появляется сразу с индикатором, отказ в записи экрана показывает панель разрешений, а не пустоту.
- Живой перевод по наведению: после выбора области задержите курсор на слове, и перевод появится рядом с ним (режим «Вся область» остаётся). Окно трёхшаговое (разрешение → область → перевод), понятные кнопки «Выбрать область…», «Пауза», «Остановить»; все точки входа ведут в одно место.
- Автоопределение языка работает на коротких словах («привет» больше не даёт ошибку); убраны лишние подписи в главном окне; кнопки режима Live показывают полные названия.
- Настройки упрощены: вкладки «Основные», «Перевод», «Приватность», «Браузеры», «Дополнительно»; разрешения — две строки с кнопкой «Разрешить…».

## 0.1.0-alpha.18

Релиз: [alpha.18](https://github.com/Slipcast-dev/translator-Koto/releases/tag/v0.1.0-alpha.18).

- Окно быстрого перевода больше не выходит за пределы экрана; в панели разрешений — подсказки (копия вне «Программ», «Сбросить и запросить заново»). Подпись выпуска привязана к идентификатору, поэтому разрешения сохраняются при обновлениях.
- Проверка локализации сопоставляет все строки в коде с каталогом, чтобы язык интерфейса не смешивался.

## 0.1.0-alpha.17

Релиз: [alpha.17](https://github.com/Slipcast-dev/translator-Koto/releases/tag/v0.1.0-alpha.17).

- Главное окно: все кнопки в одной панели инструментов в стиле macOS, разделённые по функциям.
- Окно быстрого перевода: панель разрешений со статусами, кнопкой «Разрешить…», автопродолжением команды после выдачи доступа и перезапуском для записи экрана; панель разрешений показывается только для ошибок доступа.
- Обновление: фоновая проверка при запуске (отключается), предложение с «Установить», «Позже», «Пропустить», подготовка в фоне только по согласию, вопрос о перезапуске с вариантом «Позже» (применяется при выходе).

## 0.1.0-alpha.15

Релиз: [alpha.15](https://github.com/Slipcast-dev/translator-Koto/releases/tag/v0.1.0-alpha.15).

- Обновление из GitHub Releases: раздел в настройках, проверка по кнопке, загрузка, проверка SHA-256 и подписи, замена приложения и перезапуск.
- Статус движка отражает реальное состояние (модель, ключ, список языков).

- Расширение и раздел настроек Safari.
- FAQ по получению ключей Google и Yandex.
- Исправлено переключение светлой и тёмной темы, «Системная» следует за macOS.
- Исправлена утечка `URLSession` в облачных движках; быстрее старт локальной модели (APFS-клон), выгрузка runtime в простое, Live пропускает OCR при неизменном кадре, реже просыпается native host, память переводов пишется в фоне, очищаются остатки `/tmp/koto-*` после краха.
