# Локализация расширения Chrome — этап 5

25 октября 2026 года. Статус: реализация завершена и проверена в границах этапа 5.

## Архитектура и изменения

Расширение использует стандартный chrome.i18n с каталогами [en](../BrowserExtension/_locales/en/messages.json) и [ru](../BrowserExtension/_locales/ru/messages.json), по 37 записей в каждом. В manifest задан default_locale=en; название, описание и подсказка значка используют ссылки __MSG_…__. Этот механизм выбора общего/регионального каталога и резервного языка описан в [официальной документации Chrome](https://developer.chrome.com/docs/extensions/reference/api/i18n).

[Модуль i18n.js](../BrowserExtension/i18n.js) отвечает за подписи, безопасный резервный текст, ошибки и счётчик фрагментов. Язык названий языков берётся из выбранного каталога через ui_language: неподдерживаемая локаль браузера получает согласованный английский интерфейс. ru/en — отдельный выбор от исходного и целевого языков перевода.

[Popup](../BrowserExtension/popup.js) локализует кнопки, подписи, начальное состояние, ход операции, завершение и ошибки. HTML получает корректный lang; направление оболочки ltr для ru/en. Результат имеет dir=auto и lang целевого языка. Переводы сообщений и пользовательский результат присваиваются через textContent, без интерпретации HTML.

Service worker вместо готовых русских фраз возвращает внутренние ответы:

| Действие | Ответ popup |
| --- | --- |
| Отмена | status=cancelled |
| Очистка | status=cleared |
| Перевод страницы | status=page_translated, count |
| Перевод выделения | ok, text, как раньше |

Popup формирует полную фразу счётчика через Intl.PluralRules и подстановку COUNT. Проверены 0, 1, 2, 5, 21, 22; для ru применяются one/few/many/other, для en — one/other. Остальное региональное форматирование и общие RTL-сценарии остаются в этапе 6.

Для 16 известных кодов ошибок есть подписи. В частности, excluded_page, busy, duplicate_request, invalid_request, invalid_language и invalid_action больше не сводятся только к общему сообщению. Неизвестный код и отсутствующий ключ получают понятный резервный текст без показа внутреннего кода. Указания по подготовке Apple-ресурсов не привязаны к точному тексту кнопок Koto, поскольку язык приложения может отличаться от Chrome.

## Совместимость и приватность

- ID расширения, manifest key, версия 0.1.1, разрешения, native host и внешняя схема Native Messaging сохранены.
- Изменился только внутренний формат успешных ответов worker → popup; обе стороны обновлены вместе.
- В storage остаются source/target, начальные значения auto → ru сохранены.
- Открытие на другом языке не перезаписывает языковую пару.
- Фильтрация допустимых страниц, проверка sender, ограничение объёма и политика передачи текста не менялись.
- Нет новых сетевых загрузок переводов: каталоги находятся внутри расширения.

## Проверки

Среда: Node.js 26.11.1; установленный Chrome 155.0.8059.86.

| Проверка | Результат |
| --- | --- |
| Каталоги и manifest | 37 записей en/ru, совпадение ключей и placeholders, корректные manifest-ссылки |
| Идентичность и разрешения | Сверены с прежним manifest, без изменений |
| Логика popup и worker | en, ru, en-GB, ru-RU, de-DE; selection/page/clear/cancel |
| Сохранение языковой пары | Сохранённая en → ja и начальная auto → ru; открытие popup не пишет storage |
| Ошибки | 16 кодов, неизвестный код, models_missing, unsupported_page |
| Резервный текст | Пропущенный ключ; отсутствующий перевод ru использует en в модели API |
| Счётчик | 0, 1, 2, 5, 21, 22 на ru/en |
| Изоляция worker | Чужой sender и sender из вкладки отклоняются |
| JavaScript | node --check для popup, i18n и worker |
| Протокол моста | 18 существующих проверок passed; harness компилируется |
| Форматирование | git diff --check passed |

В [BrowserLocalizationTests.mjs](../Tests/BrowserLocalizationTests.mjs) 11 тестов, все прошли. Они исполняют production popup/i18n/worker в изолированном Node VM. Chrome API и DOM подменяются на внешних границах; это логические проверки, а не автоматизация реального браузера. VM Modules требует экспериментального флага только при запуске тестов; production-расширение использует штатные ES modules Chrome.

## Проверка установленного Chrome

Через нативный интерфейс Chrome подтверждён источник установленного расширения — папка BrowserExtension проекта. Расширение перезагружено; Chrome сообщил «Перезапущено», новый popup открылся успешно.

В реальном русском Chrome проверены:

- Подписи кнопок, списков языков и уведомления о приватности.
- Сохранённая пара en → ru после перезагрузки расширения.
- Ошибка «На этой странице перевод недоступен» на служебной странице Chrome.
- Завершение отмены — «Отменено».
- Вёрстка popup на снимке: важные подписи и примечание читаются целиком.

Разрешения браузера и системный язык не менялись. Созданная для проверки вкладка расширений закрыта; пользовательские вкладки не использовались для передачи текста.

Нативный Chrome с английским языком на этом этапе не запускался. Английские состояния и резервный язык проверены в логических тестах. Полная приёмка в браузерах с разными языками относится к этапу 7. Реальный перевод страницы/выделения после локализации в Chrome не проверялся; в текущих тестах для этих действий подменены браузерная инъекция и native transport. Реальные transport-интеграции из этапа 4 сохраняются как отдельные исторические результаты.

[Машиночитаемые результаты](localization/stage5-results.json) содержат итог проверок, границы доказательств и SHA-256 изменённых файлов.

## Повторный запуск

Из корня Koto:

```sh
node --experimental-vm-modules --test Tests/BrowserLocalizationTests.mjs
./script/test_bridge_protocol.sh
```

Дополнительные npm-пакеты не нужны. Node.js необходим только для тестов; для использования расширения он не требуется.

Для установки обновлённого исходного расширения загрузите BrowserExtension через chrome://extensions; для уже установленного из этой папки нажмите «Перезагрузить». ID и ранее сохранённая пара сохраняются. DMG не пересобирался, публикация и commit/push не выполнялись.
