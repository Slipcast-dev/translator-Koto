# Изменения

## 0.1.0-alpha.17

Релиз: [Docs/RELEASE-0.1.0-alpha.17.md](Docs/RELEASE-0.1.0-alpha.17.md).

- Главное окно: все кнопки в одной панели инструментов в стиле macOS, разделённые по функциям.
- Окно быстрого перевода: панель разрешений со статусами, кнопкой «Разрешить…», автопродолжением команды после выдачи доступа и перезапуском для записи экрана; панель разрешений показывается только для ошибок доступа.
- Обновление: фоновая проверка при запуске (отключается), предложение с «Установить», «Позже», «Пропустить», подготовка в фоне только по согласию, вопрос о перезапуске с вариантом «Позже» (применяется при выходе).

## 0.1.0-alpha.16

Релиз: [alpha.16](https://github.com/Slipcast-dev/translator-Koto/releases/tag/v0.1.0-alpha.16).

- Лицензия изменена с MIT на проприетарную лицензию Koto: изменять и распространять без письменного согласия автора нельзя. Копии до alpha.15 включительно остаются на условиях MIT.
- Лицензия показана в окне «О программе»; в пакете лежит новый `LICENSE`.
- Остальное как в alpha.15.

## 0.1.0-alpha.15

Релиз: [alpha.15](https://github.com/Slipcast-dev/translator-Koto/releases/tag/v0.1.0-alpha.15).

- Обновление из GitHub Releases: раздел в настройках, проверка по кнопке, загрузка, проверка SHA-256 и подписи, замена приложения и перезапуск.
- Статус движка отражает реальное состояние (модель, ключ, список языков).
- Раздел Chromium: «Установить» и «Удалить» расширение; переключатель только включает и выключает мост.
- Расширение и раздел настроек Safari.
- FAQ по получению ключей Google и Yandex.
- Исправлено переключение светлой и тёмной темы, «Системная» следует за macOS.
- Исправлена утечка `URLSession` в облачных движках; быстрее старт локальной модели (APFS-клон), выгрузка runtime в простое, Live пропускает OCR при неизменном кадре, реже просыпается native host, память переводов пишется в фоне, очищаются остатки `/tmp/koto-*` после краха.
- Chrome 0.1.4 без изменений.
