# Koto 3.0.0 · Chrome 0.1.6

Slipcast-Dev · arm64/macOS 26+. Проверки выпуска выполнялись на macOS 27.2 / Xcode 27.2.

## Состояние

Выпуск 3.0.0: подпись ad hoc, без Developer ID и notarization — macOS может блокировать запуск. Файлы выпуска собираются workflow GitHub из исходников и подтверждаются attestation ([release notes](RELEASE-3.0.0.md)). Модель Qwen в поставку не входит и ставится кнопкой в настройках.

Перед выпуском 25.11.2026 локально прошли: Debug- и Release-сборки, `test_swift_ci.sh` (14 прогонов), ad hoc упаковка с проверкой содержимого пакета, проверка локализации Release-приложения, интеграция моста, 20 тестов расширения, проверки репозитория и локализации. Перевод при прокрутке в скриптах обоих расширений проверен на тестовой странице с имитацией API расширения.

## Лицензия и выпуски

Koto распространяется по [проприетарной лицензии](../LICENSE): изменять и распространять без письменного согласия автора нельзя, использовать официальные релизы на своих устройствах можно (копии до alpha.15 включительно остаются на условиях MIT). Выпуск автоматический: смена `CURRENT_PROJECT_VERSION` на `main` запускает сборку, attestation и публикацию релиза; сайт сам подхватывает последний релиз ([процесс](BUILDING.md#выпуск)).

## Автоматические проверки

`bash script/test_swift_ci.sh` (14 прогонов: Swift-наборы, обновление на настоящих DMG, клиент моста Safari, проверка длинного пути сокета), интеграция моста (`script/test_bridge_integration.py`), SwiftLint `--strict`, проверки репозитория и локализации (`script/validate_repository.py`, `script/validate_localization.py`), тесты Chrome. CI GitHub выполняет сборку на macOS 26, SwiftLint, Swift-наборы, CodeQL и Dependency Review.

## Не проверено

- Новое в 3.0.0 вживую в приложении: метка и значок Live, запись горячих клавиш, панели импорта и экспорта фраз, прогресс с настоящими Qwen и облаком, перевод при прокрутке внутри Chrome и Safari, откат настоящего обновления, подпись собственным сертификатом.
- Полная интерактивная приёмка на macOS 26, Live (длительность, энергия, задержки), сон/пробуждение, широкая матрица приложений.
- Работа расширения Safari внутри Safari (сборка, встраивание, подпись и клиент моста проверены; включение расширения и перевод в Safari — нет). Сборка требует «Разрешить неподписанные расширения» в Safari.
- Реальные аккаунты Google и Yandex, озвучивание, автозапуск.
- Реальная генерация и смысловое качество Qwen через текущий транспорт.
- Сквозное обновление через живой GitHub: появится при выходе выпуска новее установленного.
- Непостоянная внутренняя причина отказа Apple Translation при первом вызове не установлена; обработка отказа в Koto есть.
- Developer ID/notarization, полный App Sandbox и строгие гарантии Data Protection Keychain требуют отдельного внешнего этапа.
