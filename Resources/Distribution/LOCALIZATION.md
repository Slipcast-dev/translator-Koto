# Локализация / Localization

Koto и расширение Chrome имеют независимые интерфейсы ru/en с английским резервным языком. Языковая пара, исходный текст и технические идентификаторы сохраняются. Числа следуют региону, грамматика — языку интерфейса. Поддерживается RTL-текст.

Koto and the Chrome extension use independent ru/en interfaces with English fallback. The translation pair, original text and technical identifiers are preserved. Numbers follow the region; grammar follows the interface language. RTL text is supported.
