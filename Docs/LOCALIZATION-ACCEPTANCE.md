## Проверка первого запроса

Первоначально состояние Working было отмечено как возможное зависание, после чего запрос отменили и выполнили ручной перевод. Продолжительность ожидания до отмены тогда не измерялась. Этого было недостаточно для подтверждения дефекта.

Повторная проверка через настоящий native host дала 9 успешных первых запросов после запуска новых процессов app: 6 на текущей версии (ru/en) и 3 на исходном HEAD cc0dc484e624fa30786aa6451fc2d06a109ca101. Текущая версия отвечала за 0,114–0,547 с; исходная — за 0,483–2,761 с. Одинаковая синтетическая фраза переведена корректно. Модель и облачные API не использовались. Системные службы Apple и их кэши не перезапускались: это проверка нового процесса приложения, а не загрузки Mac с нуля.

В настоящем Chrome первый page-запрос также завершился без предварительного ручного перевода: русский Chrome с английским Koto и английский Chrome с русским Koto. Положительный результат виден на следующем снимке через 19,053 с и 14,152 с соответственно; это верхние границы времени наблюдения, включающие ожидание и вызовы CUA, а не измерение чистой задержки движка. Начальные снимки через 0,445/0,472 с показывали штатное промежуточное состояние Working.

Наблюдение закрыто как неподтверждённый дефект. Исправление зависания не заявляется; production-код движка и транспорта по этому наблюдению не менялся. Сохранена воспроизводимая проверка [test_browser_cold_start.py](../script/test_browser_cold_start.py) и [измерения](localization/cold-start-results.json). Она вернёт ненулевой exit code, если первый запрос не завершится в заданный срок.

## Поставка и проверки каталогов

validate_localization.py и LocalizationCatalogTests.py проверяют ru/en, обязательные plural-формы, параметры Foundation и Chrome, ссылки popup/manifest на сообщения, fallback и публичный ключ расширения. CI запускает также 13 тестов production JavaScript. Проверка репозитория охватывает новые неигнорируемые исходники до git add.

Упаковщик сохраняет структуру Docs, включает обе версии INSTALLATION, BUILDING, MODELS, PRIVACY, STATUS, notices и отдельные README.ru/en.txt. Инженерные ссылки на исходники в автономном пакете заменены ссылкой на краткий двуязычный отчёт. Лицензии сохранены в оригинале. --artifact-suffix сохраняет прежний опубликованный alpha-пакет.

Первый APFS DMG прошёл checksum, но чтение смонтированного каталога зависло, а DiskArbitration сначала вернул timeout. Для переносимого пакета явно выбран HFS+. HFS+ образ смонтирован, прочитан и проверен; старый APFS образ позднее успешно отключён. Первопричина сбоя APFS/среды не устанавливалась.

## Воспроизведение

Из корня репозитория:

```sh
python3 script/validate_localization.py
python3 -m unittest discover -s Tests -p LocalizationCatalogTests.py
node --experimental-vm-modules --test Tests/BrowserLocalizationTests.mjs
KOTO_CONFIGURATION=Release ./script/build_and_run.sh --build-only
python3 script/test_localization.py
./script/test_localization_dynamics.sh
python3 script/test_browser_cold_start.py --app build/DerivedData/Build/Products/Release/Koto.app --language en
python3 script/package_release.py --artifact-suffix localization-hfs
python3 script/verify_localized_package.py /path/to/mounted/Koto
```

Для проверки первого запроса app должна быть закрыта; скрипт отказывается останавливать уже запущенную копию. Он запускает только указанную сборку, выбирает Apple в launch arguments, отправляет фиксированную фразу через настоящий host и завершает созданную сессию. Личные языковые настройки не переписываются, auth token не выводится, веса не скачиваются. Это macOS-проверка с готовыми системными EN/RU ресурсами; Linux CI её не запускает.

## Границы результата

Среда: arm64, macOS 27.2, Xcode 27.1, Chrome 155.0.8059.86. macOS 26 не запускалась. Qwen отсутствует: проверены инструкции и структура ответа, но не фактическая генерация и смысловое качество. Независимая редакторская/языковая экспертиза не проводилась.

Действующая codesigning identity в Keychain не найдена. Итоговый пакет остаётся ad hoc preview, без Developer ID/notarization. При первоначальной локальной приёмке build 11 commit/push и публикация не выполнялись. Текущий выпуск alpha.12 описан отдельно выше.

После UI-проверок настройка английского языка Chrome удалена, восстановлен системный русский язык. Тестовые вкладки закрыты, ввод Koto пуст, пара en→ru сохранена. Host зарегистрирован для Release-копии из build; после установки DMG его следует зарегистрировать из установленного приложения. Оба тестовых disk image отключены.
