[Машиночитаемые результаты](validation/results.json). Ошибка отсутствующих ресурсов имитировалась только на engine boundary; системные языки не удалялись. Новая ветка восстановления не объявлена проверенной на физически удалённых языках.

Открытые ограничения: непостоянный внутренний отказ Apple framework (первопричина не установлена, исправлена обработка); запуск на macOS 26; Live endurance/энергия/задержки; сон/пробуждение; широкая матрица приложений; реальные Google/Yandex аккаунты; итоговая приёмка озвучивания/автозапуска; ошибочная idle-подпись облачного движка; смысловые ошибки Qwen; отсутствие Developer ID/notarization.

Alpha-публикация не означает завершение этих проверок. По запросу автора системная копия Koto удалена; app/DMG остаются только в локальном проекте. Старые отчёты сохранены локально вне Git, эта документация описывает текущий выпуск.
