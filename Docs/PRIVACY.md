# Данные и разрешения

Apple Translation, Vision и Qwen выполняются на устройстве. Языки Apple и Qwen могут требовать отдельной загрузки. Модель Qwen скачивается только по явной кнопке с закреплённого Hugging Face URL.

Accessibility позволяет читать выделение; если приложение его не отдаёт, Koto на мгновение копирует выделенное (⌘C) и тут же возвращает прежнее содержимое буфера обмена (парольные поля не читаются); Screen Capture — выбранную область. Названия и объём системных категорий зависят от macOS. Доступы выдаёт владелец Mac; подтверждения не обходятся. Снимки не сохраняются.

Браузерный мост по умолчанию выключен: private AF_UNIX socket, HELLO/token, собственный extension origin. Расширение читает выделение/видимые фрагменты активной HTTP(S)-страницы по действию пользователя, пропускает поля/код/editable content, передаёт origin без path/query. Исходные DOM text nodes не заменяются; переводы добавляются отдельно и удаляются кнопкой.

Облачные адаптеры используют выбранный провайдер и ключ Keychain; для capture/browser/Live нужны отдельные toggles. Автоматического fallback в облако нет. Реальные provider accounts ещё не аттестованы.

Память ручных переводов по умолчанию выключена, максимум 500 фраз; capture/browser/Live не сохраняются. Словарь точных фраз — отдельная явная настройка. Диагностический экспорт не должен включать ключи/исходные тексты.

В локализованной сборке облачные движки используют нейтральные статусы готовности и перевода. Выбранный движок и разрешения отправки видны в интерфейсе; idle-подпись не утверждает, что облачная обработка выполняется на устройстве. [Статус](STATUS.md).

## Обновления и Safari

Проверка обновлений выполняется при запуске (не чаще раза в час; отключается в настройках) и по кнопке; обращается к `api.github.com` и хостам загрузки GitHub (HTTPS, редиректы ограничены github.com и githubusercontent.com); текст переводов и ключи не передаются. Загрузка начинается только после согласия пользователя. Загруженный DMG сверяется с SHA256SUMS.txt того же выпуска; это защищает от повреждения при передаче, но не заменяет проверку издателя (подпись ad hoc, attestation встроенно не проверяется). Расширение Safari работает в песочнице с узкими исключениями: чтение токена и подключение к сокету моста Koto; те же токен, origin и каталог 0700 действуют, что и для Chrome.

## Подпись и разрешения

Выпуски подписаны ad hoc. Чтобы разрешения macOS не терялись при каждом обновлении, требование подписи задано по идентификатору `dev.slipcast.koto`, а не по хэшу сборки. Компромисс: разрешения (Универсальный доступ, Запись экрана) получает любое приложение с этим идентификатором и ad hoc подписью. Developer ID устранил бы этот компромисс.

## Границы доверия

Публичный `manifest.key` закрепляет ID распакованного расширения; это не секрет и не доказательство авторства. Другое локально установленное расширение с тем же ключом может использовать тот же ID. Мост дополнительно требует 32-байтовый токен из каталога владельца 0700 с файлами 0600. Native host проверяет UID подключённого сокета до отправки HELLO; приложение, принимающее соединение через Network.framework, UID клиента не проверяет и полагается на токен, origin расширения, каталог 0700 и проверку владельца сокета. Произвольный вредоносный процесс того же UID может читать пользовательские файлы: токен не изолирует от такой угрозы. Не устанавливайте недоверенные распакованные расширения.

Начальные исключения браузера применяются только при отсутствии `privacy.excludedHosts`. Явный пользовательский список, включая пустой, сохраняет приоритет. Начальный набор содержит отдельные почтовые, платёжные и банковские хосты, но не является полным перечнем чувствительных сайтов; дополните его в Settings. Текст и origin читаются в одном документе; добавление перевода привязано к его documentId.

При длинном UTF-8 пути Application Support используется короткий сокет в собственном каталоге 0700 под /tmp; токен остаётся в Application Support. Облачный HTTPS наследует системный proxy/PAC и по-прежнему запрещает redirects. Keychain при создании и обновлении получает одинаковый атрибут WhenUnlockedThisDeviceOnly; legacy macOS backend может его игнорировать. Строгая accessibility/device-only политика требует Data Protection Keychain и подходящей identity/entitlements. Preview не изолирован App Sandbox; TCC продолжает контролировать Screen Capture/Accessibility. Включение sandbox требует отдельного проектирования и проверки совместимости, а не неподтверждённого переключения ENABLE_APP_SANDBOX.

Модель запускается из анонимного проверенного снимка, переданного через stdin и /dev/fd/0. Исходный файл после проверки больше не влияет на загружаемые байты. На APFS снимок — мгновенный клон copy-on-write без дополнительного места; если клонирование недоступно (другой том, не APFS), делается полная копия и нужно временное место размером с модель. Именованная копия не сохраняется. Без запросов runtime выгружается через 10 минут.
