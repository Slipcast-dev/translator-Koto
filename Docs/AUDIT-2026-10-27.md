## Дополнительная проверка runtime, Capture и Live

Прочитаны LocalRuntimeSupervisor, ScreenOCRService и LiveTranslationCoordinator. Сохранены kernel peer UID/PID для каждого runtime-соединения, запрет отправки данных до проверки peer, поколения запросов/кадров и ожидание незавершённого OCR при Resume. Имеющиеся регрессии выполняются общим script/test_swift_ci.sh. Это не заменяет длительный интерактивный Live/OCR тест, испытания сна/пробуждения и реальной Qwen.

## Воспроизведение

```sh
bash script/install_swiftlint.sh
build/tooling/swiftlint/swiftlint lint --strict --config .swiftlint.yml
bash script/test_swift_ci.sh
node --experimental-vm-modules --test Tests/BrowserLocalizationTests.mjs
python3 script/validate_repository.py
python3 script/validate_localization.py
python3 -m unittest discover -s Tests -p LocalizationCatalogTests.py
KOTO_CONFIGURATION=Release bash script/build_and_run.sh --build-only
python3 script/package_release.py --artifact-suffix audit-20261027
```

Команды здесь — инструкции воспроизведения. Фактически выполненные результаты и ссылка PR/CI фиксируются отдельно в отчёте текущей проверки. Эти изменения не подменяют опубликованный alpha.13 и не отключают защиту main.

## Официальные основания

- [Apple: kSecAttrAccessible](https://developer.apple.com/documentation/security/ksecattraccessible) и [Data Protection Keychain](https://developer.apple.com/documentation/security/ksecusedataprotectionkeychain): применимость accessibility классов на macOS.
- [GitHub artifact attestations](https://docs.github.com/en/actions/how-tos/secure-your-work/use-artifact-attestations/use-artifact-attestations): происхождение артефактов и требуемые права.
- [CodeQL build options](https://docs.github.com/en/code-security/reference/code-scanning/codeql/build-options-for-compiled-languages): manual build для Swift.
