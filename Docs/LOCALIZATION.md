## 1. Цель и границы первой версии

Обеспечить полный русский и английский интерфейс приложения Koto для macOS и собственного расширения Google Chrome. Сохранить существующее поведение перевода, настройки приватности и совместимость браузерного моста.

| Локаль интерфейса | Приоритет | Основание |
| --- | --- | --- |
| ru — Русский | P0 | Текущий интерфейс и русская документация; сохранить привычные сценарии |
| en — English | P0 | Английский интерфейс и общий резервный язык; английская документация уже существует |

Это продуктовый выбор для первой версии. Данные об аудитории и рынках не собирались; рост аудитории не считается доказанным основанием выбора.

Для ru и en требуется одинаковый охват функций и состояний. Региональные варианты интерфейса отдельно не переводятся. Региональные настройки чисел, дат и единиц учитываются независимо от языка интерфейса.

Другие языки интерфейса, собственный переключатель языка, синхронизация языков между Koto и Chrome, публикация в Chrome Web Store и перевод страницы магазина не входят в первую версию. Поддержка перевода текста на уже доступные языки сохраняется, включая языки с письмом справа налево. Полная RTL-локализация оболочки относится к будущему расширению списка локалей.

## 2. Независимые языковые параметры

| Параметр | Источник значения | На что влияет |
| --- | --- | --- |
| Язык интерфейса Koto | Языковые предпочтения приложения в macOS, затем системный список предпочтений | Окна, меню, собственные сообщения, подсказки, названия языков, язык пояснений |
| Язык интерфейса расширения | Язык интерфейса Chrome и его стандартный механизм выбора локали расширения | Popup, описание расширения, статусы, ошибки, названия языков |
| Исходный язык текста | Выбор пользователя либо автоопределение | Обработка исходного текста движком |
| Целевой язык перевода | Выбор пользователя в соответствующем интерфейсе | Результат перевода и варианты перевода в пояснениях |
| Язык пояснений | Эффективный язык интерфейса Koto на момент запуска пояснения | meaning и explanation в ответе локальной модели |
| Регион форматирования | Региональные предпочтения соответствующей платформы | Представление чисел, дат, процентов и размеров |

Смена языка интерфейса не меняет сохранённые исходный и целевой языки, движок, глоссарий, память, разрешения или облачные настройки. Неподдерживаемая движком пара обрабатывается существующим сценарием проверки доступности и не исправляется сменой языка интерфейса.

Текущие начальные значения направления перевода сохраняются: source=auto, target=ru. Это правило действует при отсутствии сохранённого выбора и не зависит от языка оболочки. Изменение этих начальных значений потребует отдельного продуктового решения.

Приложение и расширение сохраняют свои языковые пары независимо. Перевод текста не ограничивается ru/en; список доступных языков по-прежнему определяется текущими возможностями движка и существующей логикой выбора языков.

## 3. Выбор языка интерфейса и резервное поведение

### Koto

1. Использовать штатные языковые предпочтения приложения в macOS; при отсутствии отдельного выбора учитывать системный порядок предпочтительных языков.
2. Выбрать подходящий язык из поддерживаемых ru/en в порядке предпочтений. Региональные варианты ru-RU, en-US, en-GB используют соответствующий общий перевод ru или en.
3. Если подходящего языка нет, использовать en. Например, список [fr-FR, ru-RU] разрешается в ru, а [fr-FR] — в en.
4. Для первой версии применять изменение языка при следующем запуске Koto. Мгновенное переключение всех окон и меню не требуется.
5. Системные диалоги macOS могут выбирать язык по собственным правилам; локализации подлежат собственные заголовки и тексты Koto.

### Расширение Chrome

1. Использовать встроенный выбор языка расширения Chrome; default_locale=en.
2. Язык Chrome и язык Koto не обязаны совпадать. Автоматической синхронизации нет.
3. Применять стандартное сопоставление региональной и общей локали Chrome; при отсутствии поддерживаемого варианта использовать английский каталог.
4. Изменение языка проверять после применения настроек и требуемого Chrome перезапуска/перезагрузки расширения; popup должен заново получать локализованные подписи при открытии.
5. При отсутствии строки использовать безопасное резервное сообщение. Пустая строка или технический ключ в пользовательском интерфейсе считаются дефектом. Резервное сообщение не заменяет требование полноты каталогов.

Названия языков отображаются на языке текущего интерфейса, а их коды остаются стабильными. При отсутствии системного названия допустим показ языкового кода. Названия брендов Koto, Slipcast-Dev, Apple Translation, Qwen, Google Cloud, Yandex Cloud и Keychain сохраняются.

## 4. Пояснения и пользовательские данные

- meaning и explanation генерируются на языке интерфейса Koto, зафиксированном при запуске запроса.
- quote содержит точный фрагмент оригинала без перевода и перефразирования.
- alternatives содержит варианты на выбранном целевом языке перевода, даже если он отличается от языка пояснения.
- При выключенных вариантах массив alternatives остаётся пустым.
- Сохраняются JSON-схема, проверка принадлежности цитат оригиналу, ограничения длины и защита от инструкций во входном тексте.
- Пояснения остаются отдельным локальным действием. Изменение локали не включает облачный маршрут и не инициирует установку модели.
- Пользовательский ввод, результаты, сохранённые фразы и записи глоссария не переводятся повторно при смене языка оболочки.
- Качество языка генерации требует отдельной проверки: наличие переведённого интерфейса не доказывает качество ответа модели.

## 5. Полный охват локализации

| Область | Обязательный охват |
| --- | --- |
| Основное окно | Ввод, результат, выбор и перестановка языков, действия, пустые состояния, лимиты |
| Подготовка перевода | Проверка ресурсов, установка языковых ресурсов Apple, прогресс, отмена, повтор |
| Захват и OCR | Выделение, выбор области, панель результата, разрешения, исключения, ошибки |
| Живой перевод | Запуск, остановка, ожидание, прогресс и ошибки |
| Локальные функции | Установка/удаление модели, состояние runtime, смысл, выражения и варианты |
| Настройки | Оформление, облачные провайдеры, Keychain, приватность, мост, импорт настроек |
| Данные и система | Точные фразы, добровольная память, автозапуск, диагностика, озвучивание |
| Оболочка macOS | Меню приложения, меню в строке macOS, Services, заголовки окон, сведения о Koto |
| Доступность | VoiceOver, пользовательские accessibility-подписи, подсказки, статусы |
| Расширение | Manifest, popup, кнопки, названия языков, примечание о приватности, состояния и ошибки |
| Установка и поставка | Пользовательские инструкции в пакете, инструкции регистрации host и установки расширения |
| Форматы | Числа, даты и размеры там, где они показываются, формы множественного числа |

Инженерные логи и машинные диагностические поля не обязаны переводиться. Собственные пользовательские ошибки переводятся; сырые ответы ОС/провайдера не используются как единственный понятный пользователю текст. Полный построчный реестр составляет этап 2.

## 7. Технические ограничения для последующих этапов

- macOS: String Catalog для UI и подходящие локализованные ресурсы Info.plist/Services; ресурсы обязательно включаются в target и итоговый пакет.
- Chrome: стандартные _locales/ru и _locales/en, сообщения через chrome.i18n, переводимые поля manifest.
- Общее между платформами — этот глоссарий и смысл сообщений. Единую библиотеку каталогов или новый TMS на первом выпуске не вводить.
- В мосте сохранять стабильные коды ошибок, идентификаторы, версию и поля протокола; пользовательские фразы формировать в отображающем интерфейсе.
- Не переводить ключи UserDefaults/storage, enum raw values, JSON-поля, bundle IDs, extension ID, имя native host, accessibilityIdentifier и сочетания клавиш.
- Сохранить совместимость импорта настроек schema=1. Новая настройка языка в первой версии не требуется.
- Не менять разрешения, ограничения облака, хранение текста, идентичность расширения и проверки происхождения запросов ради локализации.
- Отделять направление пользовательского текста от направления оболочки, корректно отображать смешанный RTL/LTR текст.
